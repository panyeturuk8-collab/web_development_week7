# SpendWise — Personal Budget & Expense Tracker

## Project Description
SpendWise is an interactive personal finance and expense tracking web application. It allows users to set a monthly budget, add and remove expenses, filter spending records by category, monitor budget health alerts, and view category-level breakdowns.

## Technologies Used
- **HTML5**: Semantic structure and accessible layout (`index.html`)
- **CSS3**: Responsive Grid and Flexbox layout, CSS custom properties, dark mode support, and interactive states (`style.css`)
- **Vanilla JavaScript (ES6+)**: State management, calculations, conditionals, loops, DOM manipulation, and event listeners (`script.js`)
- **Git & GitHub**: Version control and source code hosting
- **Netlify**: Continuous deployment and live web hosting

## Deployment Process Summary
1. Organized and pushed the complete SpendWise files (`index.html`, `style.css`, `script.js`, and `README.md`) to the public GitHub repository `web_development_week6`.
2. Connected the GitHub repository to Netlify via **Add new site → Import an existing project** and published the static site.
3. Configured a custom Netlify site name under site settings for a clean `.netlify.app` URL.
4. Verified continuous deployment by pushing an update to the `main` branch on GitHub and confirming Netlify automatically rebuilt and published the change.

## Challenges Encountered During Deployment
- Ensuring relative file paths (`style.css` and `script.js`) and case-sensitive filenames matched the repository structure so assets loaded cleanly on the live server.
- Confirming the custom Netlify subdomain was unique and updating `README.md` after the live URL was generated without leaving placeholder links behind.

## Lessons Learned
- Connecting a public GitHub repository to Netlify automates builds and updates whenever changes are pushed to `main`.
- Testing directly on the live hosted URL—and reviewing `README.md`—helps catch asset or link issues before final LMS submission.
